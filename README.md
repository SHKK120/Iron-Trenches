# Iron & Trenches

Iron & Trenches는 현재 **WWI풍 실시간 전술 / 전쟁 시뮬레이션**을 지향한다.

현재 단계는 **Foundation / Pre-Prototype**이다. 첫 목표는 회색 상자와 단순 병사 표시만으로도 이동, 화력, 엄폐, 제압, 사기, 보급의 상호작용과 전선의 움직임이 재미있는지 확인하는 Tactical Vertical Slice다.

개발을 시작할 때는 [`docs/00_시작.md`](docs/00_시작.md)를 읽는다. 상세 게임 기획과 현재 진행 상태는 해당 문서가 안내하는 각 정본 문서가 소유한다.
