# 지휘 규칙

`[현재 방향 — GAME-DIRECTION-R1]` 플레이어의 기본 지휘 단위는 병사 개인보다 분대 / 소대다. 개별 병사는 여러 명 보일 수 있지만 플레이어 조작과 전략 AI를 모든 Soldier 단위로 만들지 않는다.

## RTS 조작 기준

- 빠른 클릭 선택과 Drag Selection
- Shift Selection과 Control Group
- 우클릭 이동과 Attack Move
- 명령 재지정
- Command Grid
- 즉각적이고 읽기 쉬운 명령 피드백
- Formation, Facing / 전선 방향과 목적지의 일관된 연결

## 책임 경계

구현 중 실제 문제에 따라 조정할 수 있는 `[현재 방향]`이다.

### Squad / Platoon

- 이동 명령
- Formation
- 목표와 Tactical Target
- Tactical Intent
- Morale
- Supply State
- 전술 상태

### Soldier

- Formation slot 추종
- Local Movement
- 사격 표현과 실행
- 피격
- 간단한 Cover Position
- Visual / Animation

Squad / Platoon은 플레이어의 의도와 집단 상태를 소유하고 Soldier는 그 의도를 현장에서 표현한다.
