# 지휘 규칙

`[현재 방향]` 조작은 Squad 중심을 지향한다. Selection, Move command, 명령 재지정, Formation, Facing / 전선 방향과 목적지가 읽기 쉽고 일관되게 연결되어야 한다.

## 책임 후보

다음은 구현 전 최종 API 명세가 아닌 `[제안]`이다.

### Squad

- Command
- Destination
- Formation
- Tactical Target
- Morale
- Supply State
- Tactical Intent

### Soldier

- Formation slot 추종
- Local Movement
- Fire execution
- Damage
- 간단한 Cover Position
- Visual / Animation

Squad는 플레이어의 전술 의도와 집단 상태를 소유하고, Soldier는 그 의도를 현장에서 실행하는 방향을 시험한다. 기본 조작 단위의 최종 결정은 `50_닫을것.md`의 Q-003이 소유한다.
