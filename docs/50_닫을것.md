## Q-012 미완공 ConstructionSite의 Sector 함락 처리

- 상태: `[미정]`
- 질문: Sector 점령 시 아직 완공되지 않은 ConstructionSite를 자동 소유권 이전, 기존 소유 유지, 취소, 파괴 또는 다른 방식 중 어떻게 처리할 것인가.
- 현재 blocker: 02C의 완공된 일반 Building 이전에는 아님. ConstructionSite가 남은 실제 Match Capture 통합 전에는 결정해야 한다.

## Q-013 Terrain / Road 세부 규칙

- 상태: `[미정]`
- 질문: Terrain별 최종 이동 배율, Forest Concealment, Rocky Cover, Road 이동 보너스와 보병/차량별 차이를 어떻게 정할 것인가.
- 추가 결정: Road 건설 비용·시간, 파괴·수리, Sector 점령 시 소유권·사용권·탈취 처리
- 현재 blocker: 아님. 03B Source-Only에서는 배율을 데이터/Fixture로 주입하고 필요한 항목부터 후속 Bundle에서 닫는다.

## Q-014 이동 중 Reinforcement의 경로 단절 처리

- 상태: `[미정]`
- 질문: 출발 뒤 경로가 끊긴 증원은 재탐색, 후퇴, 현 위치 대기 또는 다른 행동 중 무엇을 선택하는가.
- 현재 03B 계약: 새 Dispatch는 현재 Strategic Supply Snapshot으로 판정하고, 기존 EnRoute 객체는 자동 삭제·Teleport하지 않는다.
- 현재 blocker: 03B 기본 Dispatch/Transit에는 아님. 실제 Match의 동적 Routing 통합 전에는 결정해야 한다.
