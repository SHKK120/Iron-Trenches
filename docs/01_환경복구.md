# 환경 복구

초기화된 새 PC에서 저장소만으로 개발을 다시 시작하기 위한 Recovery Runbook이다.

## Repository

- Repository URL: `https://github.com/SHKK120/Iron-Trenches`
- remote 이름: `origin`
- branch는 추측하지 않고 `git branch --show-current`로 확인한다.
- Clone 후 다음을 확인한다.

```bash
git remote -v
git branch --show-current
git log --oneline -5
git status
```

기존 변경이 있으면 보존하고 원인을 확인한다. 복구를 이유로 `git reset --hard` 또는 `git clean`을 사용하지 않는다.

## MCP Quality Baseline

- Unity 프로젝트가 생긴 뒤 Unity MCP 1개를 선택한다.
- 공식 Unity MCP가 당시 프로젝트 조건에서 사용 가능하면 우선 검토한다.
- 공식 MCP가 불가능하면 승인된 대체 Unity MCP 하나를 사용한다.
- Unity MCP 두 종류를 동시에 기본 활성화하지 않는다.
- Context7 / GitHub MCP는 On-Demand로 사용한다.
- 외부 AI 이미지 / 3D / Sound 서비스는 Recovery 필수 도구가 아니다.
- API Key / Token / Password를 문서 또는 Git에 넣지 않는다.
