## 운영 제약

- 현재 Codex 작업 폴더는 `.git`이 없는 `Iron-Trenches-main` 임시 반입/안전본이다.
- 고정 작업 root `C:\Users\CKIRUser\Iron-Trenches`의 정상 Clone은 완료됐고 이번 문서·스크립트 변경 4개도 반영됐다. Codex 연결 전환은 아직 필요하다.
- 관리형 PC 정책으로 Git CLI 프로세스 실행이 `Access denied` / `EPERM`으로 차단됐다.
- Git GUI 실행 파일은 존재한다.
- Codex GitHub App은 pull / push 권한을 표시했지만 실제 Contents 쓰기는 403으로 거부됐다.
- Git GUI Clone은 성공했지만 Stage에서 `update-index` 관련 Index Error가 반복돼 Commit/Push가 아직 막혀 있다.
- Unity Editor의 관리자 권한 경고가 Hub 완전 종료·재실행 뒤에도 반복됐다. 바로가기 관리자 플래그는 없고 Hub/Editor manifest는 `asInvoker`이므로 Windows 로그인 세션 또는 시설 정책의 관리자 토큰 가능성이 높다.
- 사용자 승인으로 진행한 URP Blank 진단 실행은 Burst compiler server의 named pipe 생성 실패로 `Opening project...`에서 정지했다. Hub는 총 RAM 4GB 미만 경고도 표시했다.

## Blocker

Unity 일반 사용자 실행은 현재 Windows 로그인 세션 또는 시설 정책 때문에 차단됐을 가능성이 있다. URP Blank 기준선은 Burst 보조 프로세스가 실행되지 않아 사용할 수 없다. 다음 기준선은 경량 3D Core/Built-in 템플릿으로 검증한다.
