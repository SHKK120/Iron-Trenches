- Harness: `tools/ManagedPcChecks/ManagedPcChecks.csproj`
- 대상: `Game/Assets/Scripts/Core/**/*.cs`

목표: Unity와 분리된 최소 Command + Territory domain이 현재 PC에서 컴파일되고 기본 불변조건을 지킨다.

- 직접 .NET Release build: PASS — 경고 0 / 오류 0
- ManagedPcChecks: PASS — 7 assertions
- Unity Compile / Scene / Play: DEFERRED
- 원격 보존: `main`의 Managed PC Source-Only Development Checkpoint

구현 수치, Capture 진행, 건물 소유권 이전, Frontline과 Unity adapter는 아직 포함하지 않았다.

## RTS-CORE-01B 결과

목표: 완료된 점령이 Sector 소유권을 바꾸고, 현재 소유권과 인접 관계에서 전선을 중복 없이 파생한다.

- `SectorTopology`: Sector 등록, 중복 없는 양방향 인접 관계, 인접/이웃 조회, 자기 연결 거부
- `SectorCapture` / `CaptureResult`: 점령 완료 적용, 이전/신규 소유자와 실제 변경 여부
- `FrontlineEdge` / `FrontlineResolver`: 방향 없는 경계 식별과 현재 상태 기반 전선 파생
- 3-Sector smoke: Blue West — Red Center — Red East에서 West-Center만 전선, Center의 Blue 점령 뒤 Center-East만 전선
- 직접 .NET Release build: PASS — 경고 0 / 오류 0
- ManagedPcChecks: PASS — 36 assertions; RTS-CORE-01A의 기존 7 assertions 포함
- Unity API 의존성: 없음
- Unity Compile / Scene / Play: DEFERRED

점령 시간·속도·범위·점령력·경합·감쇠·점수와 건물 이전/재가동은 포함하지 않았다. Q-007과 Q-010은 계속 `[미정]`이다.
