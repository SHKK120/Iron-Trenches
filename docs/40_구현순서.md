1. 첫 판은 North/South를 무시하고 Red Front 정면 공격 후 결과 통계를 확인한다.
2. Reset 후 둘째 판은 North와 South를 먼저 점령해 `CUT OFF`와 `Reinforcement Blocked`를 확인한 뒤 Front를 공격한다.
3. 두 결과의 시간, 손실과 적 증원 수를 비교하고 `PASS / ADJUST / FAIL`을 사람이 판정한다.

- `PASS`: 보급 차단이 의미 있고 재미있는 RTS 선택을 만들면 03B 후보 진행 가능
- `ADJUST`: 효과 강도·차단 난이도·UI를 작은 `RTS-PLAYTEST-03A-R1` Bundle에서 조정 후 재시험
- `FAIL`: 03B를 HOLD하고 보급 역할의 자동화·단순화·영향 축소·다른 효과를 새 Bundle에서 결정

사람 판정 전에는 Static Smoke나 규칙 이해를 근거로 `Human RTS Strategy/Fun Fit = PASS`로 바꾸지 않는다.
