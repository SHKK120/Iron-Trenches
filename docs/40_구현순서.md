## 관리형 PC 개발 Lane

관리형 PC에서는 이 Lane을 매 세션 기본값으로 사용한다. 개인 PC도 같은 원격 Checkpoint와 Source 검증부터 시작한 뒤 Unity 통합 검증을 추가한다.

- 필수 복구: Git Clone/Pull, Codex, 승인된 Git 경로, 브라우저
- Source 검증: `global.json`의 .NET SDK 8.0.318 / `tools/ManagedPcChecks`
- 사람 검증: `previews/index.html` Hub → 현재 `RTS_CORE_02C_ConstructionOwnership.html`
- Harness: `tools/ManagedPcChecks/ManagedPcChecks.csproj`
- 대상: `Game/Assets/Scripts/Core/**/*.cs`
- 판정 분리: `Source-Only` / `Browser Preview` / `Unity Integration`
- 관리형 PC 복구 명령: `scripts/restore-session.ps1 -Mode ManagedPc -Online`
- 개인 PC 전환 명령: `scripts/restore-session.ps1 -Mode UnityIntegration -Online`
- Unity Hub / Editor / Visual Studio 재설치: 관리형 PC의 매 세션 필수조건에서 제외
- 금지: `cmd.exe` 대체·우회, Unity Compile PASS 추정, Scene / Prefab / Component 통합 완료 추정
