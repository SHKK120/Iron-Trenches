# 나중에

RTS Core Loop가 검증되기 전의 확장을 격리한다. 국가 경제, 영토, 자유 건설, 생산, 최소 연구와 RTS 보급 자체는 후순위가 아니라 현재 전체 게임 구조다.

- 복잡한 Railway / Transport Fleet / Supply Chain Optimization
- 국가 경제의 세부 예산·세금·산업 시뮬레이션
- 대형 Tech Tree와 Doctrine 전환 전체
- 포병 고도화와 Artillery observation
- Gas
- Tank / Aircraft 콘텐츠 확장
- 장기 Campaign과 여러 국가
- 장군 성장
- Multiplayer
- Steam
- Modding
- 자유형 Trench
- 고품질 병사 Art Pipeline
- AI 3D 대량 생성 Pipeline
- 수백~수천 병사의 복잡한 개별 Soldier AI
- 세계 지도, 완전한 외교, 해전과 공중전 전체

`[대체됨 — GAME-DIRECTION-R1]` 한 전장, 20~60명, 2~3 Objective와 MASTER-A → B → C → D를 전체 게임의 구현 순서로 삼고 국가 경제·보급·시대를 후순위로 미루는 Tactical Vertical Slice 방향.

전술 시스템은 폐기하지 않는다. RTS Core Loop가 작동한 뒤 `FRONTLINE-COMBAT-01`과 `FRONTLINE-PRESSURE-01`에서 올바른 하위 레이어로 연다.

새 `wwi-rts-core-loop-playtest` Skill은 `RTS-CORE-04` 전후에 설계하며 이번 작업에서는 생성하지 않는다. `wwi-fixed-battle-playtest`도 생성하지 않는다.
