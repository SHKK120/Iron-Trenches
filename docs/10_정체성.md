# 프로젝트 정체성

## 한 문장

`[현재 방향 — GAME-DIRECTION-R1]`

> 영토와 경제, 건설과 생산, 연구와 보급을 운용해 분대·소대 단위 전선을 돌파하고 적 수도 또는 핵심 지역을 무너뜨리는 Unity 기반 Low-Poly 3D / 2.5D RTS.

전술 전투는 전체 게임이 아니라 이 RTS의 전선 전투 레이어다.

## 플레이 감각

`[현재 방향]`

- 스타크래프트 2 아케이드 / 유즈맵처럼 빠르고 명확한 RTS 조작 감각
- 빠른 선택, Drag / Shift Selection과 Control Group
- 우클릭 이동, Attack Move와 Command Grid
- Minimap과 즉각적인 명령 피드백
- 많은 부대, 병종 실루엣, 건물 기능, 영토와 전선을 빠르게 판독

2.5D는 2D Canvas 게임을 뜻하지 않는다. 실제 3D 공간과 높은 RTS 카메라를 사용하며 홍보용 고품질 3D보다 전황 판독을 우선한다.

## 한 경기의 전체 구조

`[현재 방향]`

```text
영토 / Sector와 거점
↓
지역 자동 경제와 국가 경제 / 전쟁 수행 능력
↓
자유 건설, 생산과 기술 연구
↓
후방에서 전선까지 이어지는 RTS 보급선
↓
분대 / 소대 지휘와 전술 전투
↓
전선 이동과 돌파
↓
적 수도 / 핵심 지역 승리
```

## 핵심 경험

1. 빠르고 명확한 RTS 지휘
2. 영토 확보와 전선 이동
3. 경제·생산·연구를 통한 전쟁 수행 능력 확장
4. 보급 연결과 차단
5. 화력·지형·병종 조합을 이용한 우회와 돌파

## 프로토타입 원칙

첫 구현은 Sector, 진영, 건물, 병종과 자원 수를 작게 시험할 수 있다. 다만 최종 게임 구조를 소규모 전술게임으로 바꾸지 않고 전체 RTS 구조의 축소판을 만든다.
