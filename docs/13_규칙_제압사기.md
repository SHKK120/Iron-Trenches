# 제압과 사기 규칙

이 문서는 실제 수치 없이 시스템 목적을 소유한다. Threshold와 Modifier는 향후 데이터의 `[시험값]`으로 둔다.

## Suppression

적 화력 아래에서 행동 능력이 약해지는 상태다.

효과 후보 `[제안]`:

- 조준 저하
- 이동 저하
- 명령 반응 저하
- 엎드림 / Cover 선호

## Morale

영향 후보 `[제안]`:

- Suppression
- Casualties
- Officer
- 아군 붕괴

결과 후보 `[제안]`:

- 흔들림
- Retreat
- Command delay
- Rally
