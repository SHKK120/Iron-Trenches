# 전장 규칙

첫 전장 후보는 `[제안]`이다.

```text
Friendly Rear
     │
Supply / Reinforcement
     │
Friendly Trench
     │
No Man's Land
     │
Craters / Ruins / Cover
     │
Objective
     │
Enemy Trench
     │
Enemy Rear
```

## 설계 기준

플레이어가 화면을 보고 다음을 읽을 수 있어야 한다.

- 어디가 위험한가
- 어디가 Cover인가
- 어느 곳을 MG가 통제하는가
- 어느 전선이 흔들리는가
- 어느 곳으로 우회 가능한가
- 어느 Objective가 중요한가
