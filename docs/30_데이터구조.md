# 데이터 구조

현재 책임 후보는 `[제안]`이다.

```text
UnitDefinition
WeaponDefinition
SquadDefinition
CoverDefinition
MoraleDefinition
SupplyDefinition
BattleScenario
```

## 원칙

- 병종 수치를 코드 여러 곳에 하드코딩하지 않는다.
- 같은 무기 값을 여러 파일에 중복하지 않는다.
- 문서에 실제 전투 수치를 복사하지 않는다.
- `[시험값]`을 쉽게 바꿀 수 있게 한다.
- 실제 Unity 구현 형식은 DEV-BOOT-01 이후 결정한다.

ScriptableObject 사용은 현재 자동 확정하지 않는다.
