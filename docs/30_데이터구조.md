# 데이터 구조

현재 책임 후보는 구현 전 최종 API가 아닌 `[제안]`이다.

## RTS Core 후보

```text
FactionDefinition
SectorDefinition / SectorState
StrongpointDefinition
BuildingDefinition / BuildingState
ResourceDefinition / EconomyState
ProductionDefinition / ProductionQueue
ResearchDefinition / ResearchState
SupplyNode / SupplyConnection / SupplyState
SquadDefinition / PlatoonState
UnitDefinition / SoldierState
CapitalOrCoreRegion
MatchState
```

## 전선 전투 후보

```text
WeaponDefinition
CoverDefinition
MoraleDefinition
BattleScenario
```

## 책임 경계

- Sector는 소유권, 거점, 경제 가치, 건물과 보급 연결을 연결한다.
- Squad / Platoon은 명령, Formation, 목표, Morale과 Supply State를 소유한다.
- Soldier는 Squad 의도를 표현하는 local movement, 사격, 피격과 시각 상태를 담당한다.
- 일반 건물의 Sector 점령 이전과 적 유닛 / 참호 예외를 데이터와 코드에서 구분할 수 있어야 한다.

## 원칙

- 실제 수치와 콘텐츠 값을 문서나 코드 여러 곳에 중복하지 않는다.
- `[시험값]`은 쉽게 바꿀 수 있어야 한다.
- 프로토타입의 작은 데이터 수가 최종 게임 규모를 제한하지 않는다.
- HTML Prototype의 고정 Build Slot, 임시 수치, Canvas 객체와 AI 구조를 정본으로 복사하지 않는다.
- ScriptableObject와 DOTS 사용 시점은 자동 확정하지 않는다.

이는 관리형 PC용 Source-Only 기술 기준선이다. 모든 일반 `ConstructionSite`와 완공 `BuildingState`는 정확히 하나의 `SectorId`를 가지지만 RoadSegment는 여러 Sector를 가로지르는 별도 Infrastructure다. Road endpoint는 고정 Slot이 아닌 자유 WorldPoint이고 연결 Junction은 endpoint에서 동적으로 파생한다. Supply는 SectorState나 BuildingState의 영구 flag가 아니라 현재 Owner, Topology와 Supply Source에서 매 Resolve마다 파생한다. 기술 `CutOff`는 아군 Territory 경로가 없는 완전 고립만 뜻하며, 적 병력·방어진지의 Route Threat와 독립적이다. Road가 없어도 Strategic Supply가 연결되어 있으면 Reinforcement는 Offroad로 이동할 수 있다. 위협은 이동 시간과 함께 Dispatch 시점 Route 선택에만 쓰며 유일한 위험 경로를 금지하지 않는다. 선택된 Route와 위협 평가는 Transit의 불변 Snapshot이고 이동 중 위협 변경에 따른 자동 재탐색·피해는 없다. 이동 중 파괴는 `DestroyedEnRoute`이며 StrategicSupplyStatus에 Interdicted를 추가하지 않는다. 완전 고립은 신규 Dispatch를 막지만 Ready나 이미 EnRoute인 객체를 삭제·Teleport하지 않는다. 생산 완료는 실제 Building 위치의 `ReadyAtSource`를 만들고 기존 Dispatch를 통과해야 전장 이동을 시작한다. 완공 생산시설 점령은 기존 일반 Building 이전 결과를 재사용하며 Q-015 확정 규칙에 따라 기존 Queue만 취소한다. 경제·Ready·Transit은 해석 입력이 아니므로 환불·자동 이전·삭제가 발생하지 않는다. Research는 Faction별 상태와 기존 EconomyState 비용을 사용하며 완료 ID만 조회할 수 있고 실제 효과는 적용하지 않는다. 진영당 Active Research 1개는 04A `[시험 구조]`다. 이동 중 경로 단절 뒤 재탐색/후퇴/대기는 Q-014, 보급의 생산 효과는 Q-016, Route Threat 최종 가중치와 AI 강행 판단은 Q-017, 점령된 Source의 Ready 최종 처리는 Q-018이 소유한다. 최종 Research Tree/Tier/Doctrine/시설/병렬 슬롯은 Q-011이 소유한다. Terrain/Road/Threat Fixture 배율·반경·가중치와 Production·Research 비용·시간은 `[시험값]`이다. Browser Preview의 JavaScript는 게임 기술 정본이 아니며 실제 Combat, Unit/Outpost/Trench Core, Road 파괴와 Unity Component 연결은 구현한 것이 아니다.
