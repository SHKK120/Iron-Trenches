# 병종

초기 병종 후보는 모두 `[제안]`이다. 이들은 고정 소규모 전투 전용 병종이 아니라 생산 건물에서 생산되어 Sector와 전선을 오가는 RTS 부대 후보다.

## Rifle Squad

기본 전선 유지 / 공격.

## Machine Gun Team

공간 통제 / 강한 Suppression.

## Officer / Command Unit

Rally / Command / Morale 역할 후보.

## Engineer

Trench / Wire / Fieldwork와 연결되는 역할 후보.

## 후순위 후보

- Medic
- Mortar Team

병종은 능력 버튼 숫자가 아니라 전장에서 맡는 위치와 역할이 달라야 한다.
