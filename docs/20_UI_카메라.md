# UI와 카메라

현재는 거대한 UI를 설계하지 않는다. 높은 RTS / Tactical Camera 후보 아래 전황 판독에 필요한 정보부터 표시한다.

## 우선 표시 정보

- Selected Squad
- Move Target
- Cover State
- Suppression
- Morale
- Ammo
- Objective
- Supply State
- 필요할 때 MG Danger Zone

## 하지 않는 것

- 모든 병사의 체력바
- 거대한 국가 경제 UI
- 세부 통계 수십 개
- 캠페인 UI

> UI는 전황 판독을 돕는 시스템이다.
