# UI와 카메라

`[현재 방향 — GAME-DIRECTION-R1]` 실제 3D 공간을 높은 RTS 시점에서 본다. UI는 많은 부대와 영토, 건물, 경제, 보급과 전선을 빠르게 판독하고 명령하는 시스템이다.

## 조작 UI

- 클릭 / Drag / Shift Selection
- Control Group
- 우클릭 이동과 Attack Move
- Command Grid
- Placement Mode와 Ghost Preview
- 즉각적인 이동·공격·건설 명령 피드백
- Minimap

## 우선 표시 정보

- 선택한 Squad / Platoon과 명령 상태
- Move / Attack Move Target
- Sector 경계와 Ownership
- 거점 점령 상태
- 자원과 지역 자동 수입
- 건물 기능, 생산 Queue와 연구 상태
- Supply connectivity와 Cut-off
- Frontline, Capital / Core Region
- 필요한 시점의 Cover, Suppression, Morale, Ammo와 MG Danger Zone

## 시각 기준

- Low-Poly Asset과 명확한 병종 실루엣
- 아군 / 적군 / 중립의 즉시 구분
- 건물 기능과 배치 가능 여부의 즉시 구분
- 지역 경계, 전방 / 후방과 전선 이동의 명확한 표시
- 많은 부대가 있어도 개별 병사 체력바와 과도한 통계로 화면을 가리지 않음

두 HTML Prototype은 RTS HUD와 조작·전장 판독 참고자료일 뿐 Canvas 코드, 임시 수치와 고정 Build Slot을 Unity로 이식하지 않는다.
