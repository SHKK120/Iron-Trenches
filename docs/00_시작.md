# 시작

## 문서의 역할

모든 Iron & Trenches 작업을 시작할 때 필요한 최소 문서로 안내하는 문서 Router다.

## 이 문서가 소유하는 정보

- 프로젝트 환경의 짧은 요약
- 공통 작업 용어
- 작업 종류별 문서 라우팅
- 문서 / 데이터 / 코드의 정본 원칙

## 이 문서가 소유하지 않는 정보

- 실제 PC 경로와 도구 버전
- 현재 Result Bundle의 상세 상태
- 게임 시스템의 상세 규칙
- 실제 전투 수치
- 구현 코드와 Asset

## 환경 요약

- 프로젝트 저장소 및 복구 환경의 정본: `01_환경복구.md`
- 엔진: Unity 방향. 정확 버전과 실제 적용 상태의 정본은 `01_환경복구.md`
- 현재 Result Bundle과 다음 행동의 정본: `40_구현순서.md`

과거 Unity / DOTS 기술 방향은 현재 설치 상태나 버전 확정을 뜻하지 않는다.

## 용어

개발 작업 단위는 `Result Bundle`이라 부른다. 각 Bundle은 기술 확인과 사람 확인을 구분한다.

## 정본 원칙

- 문서 = 왜 / 의미 / 경계
- 게임 데이터 = 실제 수치와 콘텐츠 값
- 코드 / Scene = 현재 구현
- `01_환경복구.md` = 환경과 복구
- `40_구현순서.md` = 현재 작업 상태
- `50_닫을것.md` = 열린 결정
- `60_나중에.md` = 후순위
- `지시장부.md` = 실제 지시와 변경 이력

한 사실을 여러 문서에서 동시에 확정하지 않는다. 다른 문서에서 필요하면 소유 정본을 짧게 참조한다.
