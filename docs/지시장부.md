## 003 — FOUNDATION-02 Recovery Hardening

### ▶ 지시

군 싸지방처럼 PC가 초기화되는 제약을 환경 복구 기준에 포함한다.

### 한 일

- 로컬 상태가 사라지는 무상태 환경을 복구의 기본 전제로 명시했다.
- ZIP 대신 Git Clone과 `origin/main` Checkpoint를 복구 원본으로 지정했다.
- Clone 후 필수 파일, remote, branch, log, status와 원격 HEAD 일치를 검사하는 스크립트를 추가했다.
- Unity 생성물, IDE 상태, Codex 개인 설정과 인증정보를 제외하는 `.gitignore`를 추가했다.
- 세션 종료 전 commit/push 및 다음 재개 지점 기록 절차를 명시했다.

### 안전 경계

- 기존 폴더를 삭제하거나 덮어쓰지 않는다.
- 자동 merge, checkout, reset, clean, pull, push를 하지 않는다.
- 인증정보와 보안 우회 절차를 저장하지 않는다.

### 다음

GitHub App 쓰기 연결을 복구한 뒤 FOUNDATION-02 원격 Checkpoint를 완료한다. 완료 후 `DEV-BOOT-01 — Unity Development Baseline`으로 이동한다.
