### 범위 밖

- Unity 프로젝트
- Unity MCP 및 다른 MCP 설치
- Project Skill
- 게임 코드와 Asset

### 다음

GitHub App을 계정 `SHKK120`에 설치하고 `Iron-Trenches` 저장소 쓰기 접근을 허용한 뒤 FOUNDATION-02 원격 Checkpoint를 완료한다.

### 미완료 / Blocker

- 로컬 명령 실행이 Windows 정책에서 거부되어 `.git` 초기화와 로컬 검증을 실행하지 못했다.
- GitHub 저장소 읽기는 확인했으나 Contents 쓰기는 403으로 거부됐다.
- GitHub App 설치 목록이 비어 있으므로 현재 로컬 복구 파일은 아직 PC 초기화를 견디지 못한다.

정확한 commit hash는 이 문서에 자기참조로 기록하지 않고 Git과 최종 보고에서 확인한다.

## 003 — FOUNDATION-02 Recovery Hardening

### ▶ 지시

군 싸지방처럼 PC가 초기화되는 제약을 환경 복구 기준에 포함한다.

### 한 일

- 로컬 상태가 사라지는 무상태 환경을 복구의 기본 전제로 명시했다.
- ZIP 대신 Git Clone과 `origin/main` Checkpoint를 복구 원본으로 지정했다.
- Clone 후 필수 파일, remote, branch, log, status와 원격 HEAD 일치를 검사하는 스크립트를 추가했다.
- Unity 생성물, IDE 상태, Codex 개인 설정과 인증정보를 제외하는 `.gitignore`를 추가했다.
- 세션 종료 전 commit/push 및 다음 재개 지점 기록 절차를 명시했다.

### 안전 경계

- 기존 폴더를 삭제하거나 덮어쓰지 않는다.
- 자동 merge, checkout, reset, clean, pull, push를 하지 않는다.
- 인증정보와 보안 우회 절차를 저장하지 않는다.

### 다음

GitHub App 쓰기 연결을 복구한 뒤 FOUNDATION-02 원격 Checkpoint를 완료한다. 완료 후 `DEV-BOOT-01 — Unity Development Baseline`으로 이동한다.

## 004 — FOUNDATION-R1 Recovery Architecture Alignment

### ▶ 지시

RPGpro에서 실제 초기화 PC 복구에 사용한 구조 원칙을 기준으로 Iron & Trenches의 문서·복구·검증 책임을 재정렬한다. RPGpro의 게임 규칙, Godot, Blender, Scenario와 아트 제작 규칙은 가져오지 않는다.

### 한 일

- `00_시작.md`를 최소 문서 Router로 축소하고 현재 Result Bundle과 실제 환경값의 중복 소유를 제거했다.
- `01_환경복구.md`를 정상 Clone, 실제 환경값, 관리형 PC fallback, Unity/MCP/Skill 복구와 Q0의 단일 정본으로 강화했다.
- Codex GitHub App을 필수 복구조건이 아닌 선택 편의 도구로 내렸다.
- `restore-session.ps1`을 PASS / FAIL / SKIP / BLOCKED 기반의 기계적 검사 전용 도구로 한정했다.
- `.codex/config.toml`, Secret, Cache, Log, 개인 설정과 Git 보존 대상의 경계를 명확히 했다.
- `.agents/skills/**`를 향후 Git 정본 후보로 두되 FOUNDATION-R1에서는 Skill을 생성하지 않았다.
- `40_구현순서.md`만 현재 Result Bundle, blocker, 원격 Checkpoint와 다음 행동을 소유하도록 정리했다.

### 확인 범위

- 지정된 시작 파일 7개의 존재와 최신 로컬 내용을 확인했다.
- Router 경로와 실제 Foundation 파일 존재를 확인했다.
- 검사 스크립트에서 파괴적 Git, 설치, 권한 상승, Execution Policy 완화와 보안 우회 동작이 없음을 정적으로 확인했다.
- `.gitignore`가 Unity 생성물, IDE 상태, `.codex`, Secret 후보와 Log를 제외하고 프로젝트 정본 경로를 제외하지 않음을 확인했다.
- 게임 디자인 규칙, Unity 프로젝트, MCP와 Project Skill은 변경하거나 생성하지 않았다.

### 상태

- 사람 확인: 완료 — Checkpoint 반영 범위 승인
- 원격 보존: `main`의 FOUNDATION-R1 Checkpoint
