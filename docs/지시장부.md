# 지시 장부

## 001 — FOUNDATION-01

### ▶ 지시

빈 Iron & Trenches 저장소에서 프로젝트를 다시 시작한다.

게임 코드에 들어가기 전에 문서 정본과 PC 초기화 복구 기반을 만든다.

### 자리

- Repository root
- AGENTS
- README
- docs 정본 구조
- Recovery Runbook

### 한 일

- Repository root에 짧은 작업 Router와 외부 소개를 생성했다.
- 기획 영역별 정본 문서와 현재 진행 Dashboard를 생성했다.
- 초기화 PC용 Recovery Runbook과 보안 원칙을 생성했다.
- 과거 확인, 현재 방향, 제안과 미정을 분리했다.
- Unity 프로젝트, 게임 코드, Asset과 Project Skill은 생성하지 않았다.

### 바뀐 정본

- `AGENTS.md`, `README.md`, `.gitignore`
- `docs/00_시작.md`, `docs/01_환경복구.md`
- `docs/10_정체성.md`부터 `docs/15_규칙_전장.md`
- `docs/20_UI_카메라.md`
- `docs/30_데이터구조.md`, `docs/31_병종.md`
- `docs/40_구현순서.md`, `docs/50_닫을것.md`, `docs/60_나중에.md`
- `docs/지시장부.md`, `docs/기록함/README.md`

### 확인

기술:

- Git 상태
- 파일 존재
- 문서 구조
- 경로
- Secret 여부

사람:

- 프로젝트 분리
- 문서 범위
- Recovery 이해도

### 미확인

- Unity 정확 버전
- Unity 실제 프로젝트
- DOTS 설치 여부
- Unity MCP
- 실제 전투 시스템
- 게임 재미
