# 보급 규칙

`[현재 방향 — GAME-DIRECTION-R1]` 보급은 단순 Squad Ammo Bar가 아니라 영토와 전선을 연결하는 전략 RTS 시스템이다.

```text
수도 / 후방
↓
아군 소유 영토
↓
연결된 거점 / 보급망
↓
전방 Sector
↓
전선의 분대 / 소대와 시설
```

영토가 고립되거나 연결이 끊기면 그 지역의 전쟁 수행 능력이 떨어져야 한다. 정확한 패널티, 거리 계산, 전달 주기와 보급 자원 종류는 게임 데이터와 구현 시험을 통해 정한다.

초기 `RTS-CORE-03`에서는 다음의 최소 상호작용을 검증한다.

- 아군 영토의 연결 상태
- 후방에서 전선까지의 Supply connectivity
- 전략 연결 완전 단절에 따른 완전 고립 판정
- 부대와 지역의 읽기 쉬운 Supply status
- 생산·증원과 전선 유지의 연결

Railway, 수송대 최적화, 복잡한 공장 물류망은 이 최소 구조가 검증된 뒤 확장한다. 보급 연결이 자유 건설의 필수조건인지는 `50_닫을것.md`가 소유한다.

## 전략 연결과 실제 병력 흐름

`[현재 방향 — 사용자 확인]` 보급은 단순 상태 UI가 아니라 실제 전장의 병력 흐름과 연결한다.

- 후방에서 생성된 증원은 실제 전장을 이동해 전선에 도착할 수 있다.
- 적의 후방 침투로 이동 중인 증원을 직접 발견하고 요격할 수 있다.
- Sector 연결이 남은 상태에서 이동 병력을 공격하는 물리적 Interdiction은 전략적 완전 고립과 구분한다.
- 핵심 Corridor Sector를 점령해 후방과 전선 사이의 아군 소유 경로가 모두 사라질 때 완전 고립이 된다. 기존 기술 enum의 `CutOff`는 이 의미만 유지한다.
- 점령한 차단 지점을 참호와 방어시설로 고착하는 전략은 향후 전선 전투 시스템과 연결한다.

정확한 보급 패널티, 수송량, 전달 주기, 증원 중단 처리와 도로 의존도는 여전히 `[미정]`이다. 현재 Source-Only Core에서는 아군 Territory 경로가 없는 기술 `CutOff`, 즉 완전 고립일 때만 신규 Reinforcement Dispatch를 중단한다.

## 보급로 위협과 완전 고립

`[현재 방향 — 사용자 확정 / RTS-CORE-03D]` 전략 연결과 실제 이동 경로의 위험은 서로 독립적이다.

- 적 병력이나 적 방어진지가 보급로 주변에 존재하면 해당 경로는 위험해지지만 물리적인 이동 가능성은 사라지지 않는다.
- 적 이동 병력은 `보급로 위협`, 전초기지·참호·강한 방어진지 입력은 더 높은 `강한 보급로 위협`을 만들 수 있다.
- 대체 경로가 있으면 Reinforcement는 이동 시간과 위험을 비교해 더 나은 경로를 선택할 수 있다.
- 다른 경로가 없으면 위협 또는 강한 위협이 있는 경로도 강행 이동할 수 있다.
- 실제 적 병력과 이동 중 증원이 교전해 파괴되는 물리적 Interdiction은 `DestroyedEnRoute`로 표현하며 전략 연결 상태를 자동 변경하지 않는다.
- 적 병력 또는 적 전초기지의 존재만으로 Sector Owner가 바뀌지 않는다. Territory Capture는 기존 Anchor 규칙이 소유한다.
- 후방과 목적지 사이의 아군 Territory 경로 자체가 하나도 없을 때만 `완전 고립`이며, 이때만 신규 Dispatch를 차단한다.
- Road가 없으면 Offroad 이동이 가능하므로 Road 부재도 완전 고립과 같지 않다.

03D의 위협 반경·가중치와 이동 시간 대비 위험 점수는 `[시험값]`이다. 실제 피해, 전투력 비교, 호위 효과와 AI 강행 기준은 Q-017, 이동 중 재탐색은 Q-014가 소유한다.

## 생산과 출발지 증원 연결

`[현재 구현 — RTS-CORE-03C]` 생산 완료는 전선에 병력을 즉시 생성하지 않는다.

- 생산 완료 결과는 해당 생산 시설의 실제 `Position`과 `SectorId`에 있는 `Ready At Source`다.
- 출발 대기 병력은 기존 03B 파견 계약을 거쳐 `EnRoute → Arrived`로 이동하며, 연결 도로가 있으면 도로를 우선하고 없으면 야지 경로를 사용한다.
- 전략 보급이 기술 `CutOff`, 즉 완전 고립이면 새 파견만 거부한다. 생산과 이미 완료된 출발 대기 객체는 삭제·이전하지 않는다.
- 연결 복구 뒤에는 같은 출발 대기 ID를 다시 파견할 수 있다.
- 03C 시험에서는 완전 고립이 생산 진행 자체를 늦추거나 막지 않는다. 생산 속도·비용·가동 가능 여부에 미칠 최종 효과는 Q-016이 소유한다.
- 생산 중 시설 소유권 변경 시 대기열을 자동 이전·삭제하지 않고 `OwnershipConflict`로 정지한다. 최종 대기열 처리 정책은 Q-015가 소유한다.
